# 需求与决策记录（防断片）

> 仓库完全开源（MIT）。本文件是**项目文件**，不是源码，按约定与 `app/` 同放一个仓库。
> 对话断了、换模型了、隔几天回来、新人来共创 —— 先看这份，再看 README。

## 一、需求原话（逐条落档）

1. 场景：AI 对话里每次都要手动加一段**固定提示词**，不加就「降智」、只凭上下文乱答。
2. 想要：点一下就把预设提示词**贴进输入框**，不用在 App 之间复制粘贴。
3. 迭代过的取舍：
   - 不要 2022 年停更项目，要 2025/2026 年还在更新的；
   - 链接**一个代码框一条**，别堆一起；
   - 中文友好；
   - **不要一堆多余功能**，只要「粘贴提示词」这一件事干好。
4. 定案：**不做输入法**，做成**悬浮窗 App** —— 平时小悬浮球，点开展成一排预设提示词，
   点一条就进当前输入框，**不跟输入法抢**；提示词增删改在主页面做；要有完整项目文件防断片。
5. v0.1.0 追加：页面用代码画出来自己看一眼、不合适就改；新建开源仓库并维护好；
   上游来源说清楚；LOGO 和名字自己设计；包推 Releases 给订阅地址。
6. **v0.1.1 本轮追加**：
   - **核心 bug**：悬浮球点一下展开、立马自动收起 → 必须先跑通；因为没跑通，粘贴功能还没真机测过。
   - 新增**一键导出开发者日志**（MD），记录运行 / 排 bug 相关信息，「回头贴日志你就知道问题出在哪」。
   - **固定包名**，不要每次安装都卸载重装。
   - 本轮**要出包**，项目文件也要同步到 GitHub，但**项目文件不是软件源码，放同一个仓库、分开目录**。
   - 软件界面做得垃圾、冗余、"仿人类"：都打开软件了还显示名字 LOGO 干什么？现代软件不该这样，软件是给人用的 → 极简。
   - **每次出包升一个小版本**，就这么迭代。
7. 用户给我加的「系统提示」：用户想法不一定对，要有自主判断；说错要指出、不完善要纠正；
   **动手前把需要核实的跟用户说清楚**；做软件要有项目文件防断片；不要什么都手搓，多去 GitHub 借鉴。

## 三、v0.1.1 核心 bug 的根因与修法（★ 最重要）

**现象**：点悬浮球 → 面板展开 → 立刻自己收起。

**根因**：`PasteAccessibilityService.onAccessibilityEvent()` 里旧逻辑是
「收到 `TYPE_WINDOW_STATE_CHANGED` 就 `collapsePanel()`」。
但我们自己 `wm.addView()` 添加 `TYPE_ACCESSIBILITY_OVERLAY` 面板时，系统**马上**会派发一次
windowStateChanged 事件 → 面板刚加上就被自己收掉了。键盘弹出 / 输入法窗口变化也会发同一事件，同样误收。
这是 v0.1.0 我自作主张加的「切窗口自动收起」，用户没要求，反而把核心功能弄废了。

**修法**：**彻底不用无障碍事件收起面板**。收起只发生在用户明确操作时
（点收起 ✕、点提示词插入后、再点一次球、服务销毁、设置刷新）。
`onAccessibilityEvent()` 只做诊断埋点，并且把订阅事件收窄到
`typeWindowStateChanged|typeViewFocused`（去掉高频 text/content 事件，避免日志刷屏）。
`collapsePanel(reason)` 带原因写进日志，一眼能看出是谁收的。

## 四、技术决策（累计）

- **悬浮层**：`TYPE_ACCESSIBILITY_OVERLAY`，**不申请 `SYSTEM_ALERT_WINDOW`**，Manifest 零 `uses-permission`。
- **不抢焦点**：所有浮窗强制 `FLAG_NOT_FOCUSABLE`；抢焦点会让 `FOCUS_INPUT` 返回 null。
- **插入链**：PASTE 优先（保光标、不覆盖草稿）→ SET_TEXT 兜底（按选区拼接）→ 剪贴板兜底；成功后还原原剪贴板。
- **焦点定位**：`FOCUS_INPUT`，不用 `FOCUS_ACCESSIBILITY`；`node.recycle()` 必做。
- **面板定位**：`computePanelY(实际高度)`，球在下半屏时翻到球上方；球 `y` 夹在 `screenH - 220dp` 以上，不压键盘。
- **球 ↔ 框（v0.1.3）**：单个 `FrameLayout` + `ValueAnimator` 逐帧改 `WindowManager.LayoutParams` 的
  w/h/x/y 与 `GradientDrawable.cornerRadius`（28dp 正圆 → 16dp 圆角），球文字淡出、内容淡入；
  展开时 `ballView.visibility = INVISIBLE`，二者从不同框并存。220ms / 180ms，`DecelerateInterpolator`。
  动画结束回调加 `morphAnimator !== va` 身份判断，避免 `cancel()` 触发旧 `onEnd` 递归移除。
- **浮窗标志**：`FLAG_NOT_FOCUSABLE` + **`FLAG_NOT_TOUCH_MODAL`**（后者保证框外触摸穿透给输入框/键盘，
  代价是「点框外不收起」，收起改由点框内空白承担）。
- **预览态**：`HorizontalScrollView` ↔ `ScrollView` 在同一个 `contentRoot` 内切 visibility，
  给 ScrollView 有界高度（`min(screenH/2, 320dp)`）让长文在框内滚动。
- **宽度自适应**：`TextView.paint.measureText(标题)` 累加 chips 宽 + padding，clamp 到屏宽-32dp。
- **数据层**：`SharedPreferences` + `org.json`，零依赖。
- **UI**：原生 View/XML，无 Compose / AndroidX。v0.1.1 极简：砍掉品牌头、LOGO、副标题、版本标签、用法长句、状态解释行、底部提示；只留「一行状态 + 列表 + 三个动作」。
- **联动**：`PasteAccessibilityService.instance` 同进程直连 `refreshFromSettings()`；每次展开重新 `repo.list()`。
- **开发者日志**：`DevLogger` 单例，内存环形缓冲 800 条 + 私有 `dev_log.ndjson` 逐条追加落盘（进程被杀也能读回）；
  导出 Markdown 含环境快照 / 错误汇总 / 完整时间线 / 隐私说明 / 复现步骤占位。
  **绝不记用户内容**，只记事件、布尔值、数量、长度。
- **签名**：`app/debug.keystore` 公开开发签名入库，`debug` 与 `release` 构建都用它 → 覆盖安装免卸载。
- **版本**：唯一版本源 `versionName`；CI `sed` 读它生成 `v${version}` tag；
  APK 名 = `Citie-v${version}.apk`（GitHub asset 名不支持中文，中文放 label）。
- **构建**：minSdk 26 / targetSdk 34 / compileSdk 34，AGP 8.5.2 + Kotlin 1.9.24 + Gradle 8.7 + JDK 17；
  CI 用 runner 自带 Android SDK（第三方 `setup-android` action 曾导致失败，已去掉）。
