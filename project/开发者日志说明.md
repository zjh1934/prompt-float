# 开发者日志说明

> 目的：**你把日志贴过来，我就能知道软件问题出在哪**，不用猜、不用问「你点了啥」。

## 一、怎么导出

主页面底部 **「导出日志」** 按钮，点一下：

1. 生成 Markdown 文档，写到应用私有目录 `promptfloat-dev-log.md`；
2. 全文复制到剪贴板；
3. 打开系统分享面板（可以直接发给我 / 发到任意聊天 / 存到笔记）。

整份贴过来就行。想留档：主页面右上角 `⋯` → **清空日志** 会先把当前这份存成 `.md` 文件再清空，
适合「从干净起点复现一次 bug」。

## 二、日志里有什么

**环境快照**（排 bug 最常缺的就是这部分）：

- 版本 / versionCode / **包名**
- 厂商机型、Android 版本、API level、ABI
- 无障碍是否已启用、悬浮球开关、悬浮服务实例是否在运行
- 提示词条数、日志条数

**事件时间线**，每行是 `时间 | 级别 | 标签 | 事件`。标签含义：

| 标签 | 记什么 |
|---|---|
| `APP` | 进程启动、仓库初始化 |
| `SERVICE` | 无障碍服务 onCreate / onServiceConnected / onInterrupt / onDestroy / 设置刷新 |
| `A11Y` | 收到的无障碍事件类型与来源包名（500ms 节流，不刷屏） |
| `BALL` | 悬浮球创建 / 移除 / 拖拽贴边 / 点击 |
| `PANEL` | `morph expand`（含目标宽高与位置）/ `morph collapse(reason=…)` / `preview open` / `长按第 N 条` / `computePanelY flip=…` / 面板 addView 成败 |
| `INSERT` | focus 是否命中、节点类型、选区、PASTE 结果、SET_TEXT 结果、走哪条兜底 |
| `UI` | 主页面生命周期、每个按钮点击、日志导出 |
| `DATA` | 提示词增删改、备份导入导出（只记数量与长度） |

**错误汇总**：单独把最近 30 条 `E/W` 提到最前面，不用在几百行里翻。

## 三、隐私红线（重要）

日志**不包含**：

- 提示词正文、输入框里的文字、你打的一半草稿
- 剪贴板内容
- 屏幕 / 窗口上的任何文本
- 聊天记录、账号、包名以外的标识

只记「发生了什么、成功还是失败、类型、数量、长度」。
所以整份日志可以放心贴给我，或者直接开公开 issue，不会泄漏你的内容。
例如 `INSERT 开始 | 文本长度=86` —— 只有长度，没有那 86 个字。

## 四、日志模式 → 问题定位对照

| 你看到的现象 | 日志里长这样 | 结论 |
|---|---|---|
| 点一下展开马上收起（v0.1.0 的 bug） | `PANEL morph expand` 紧跟 `morph collapse(reason=a11y-event)` | 自己添加 overlay 触发的 `WINDOW_STATE` 事件把面板收了 → v0.1.1 已移除该自动收起；v0.1.3 起**任何** `a11y-event` 都不该出现 |
| 球和框同时显示 / 动画卡住 | 有 `morph expand` 但没有后续 `collapse`，或 `collapse` 一直没 `collapse now` | v0.1.3 动画回调有身份判断；若卡住，贴日志看 `animating` 是否未复位 |
| 长按没反应 / 预览态撑满屏 | 没有 `长按第 N 条` 或 `preview open` | 检查 `PANEL preview open` 里的目标高度；`ScrollView` 有界高度 = `min(screenH/2, 320dp)` |
| 点框外没反应（不是 bug） | 只有 `A11Y` 事件，没有 `collapse` | **刻意设计**：`FLAG_NOT_TOUCH_MODAL` 让框外触摸穿透给输入框；收起要点框内空白（`reason=tap-blank`） |
| 点提示词没反应 | `INSERT focus=null` | 没有聚焦输入框：输入框失焦 / 悬浮窗抢了焦点 / 自绘控件不暴露焦点 |
| 提示词只进了剪贴板 | `paste=false` + `setText=false` + `结果=两个动作都被拒绝` | 宿主 App 拒绝两个动作（Flutter / WebView / 密码框），已走兜底，需手动长按粘贴 |
| 悬浮球根本不出现 | 没有 `SERVICE onServiceConnected`，或 `BALL 开关为关` | 无障碍没开，或主页面把球关了 |
| 面板被键盘挡住 | `PANEL computePanelY flip=false` | 翻转判断没生效，检查屏幕高度 / 预估高度 |
| 服务用着用着没了 | `SERVICE onInterrupt` 或 `onDestroy` | 系统回收 / 省电限制 / 无障碍被自动关闭 |
| 覆盖安装失败 | 快照里包名一致但安装报错 | 签名变了 → 核对 CI「校验签名」打印的 SHA-256 |
| 改了提示词球里没变 | 没有 `SERVICE refreshFromSettings` | 主页面与服务没联动（同进程直连失效） |

## 五、贴日志时顺手补一句

日志末尾有一行 HTML 注释占位，请补上：

```
复现步骤：
1. 在哪个 App（名称 + 版本）
2. 点了什么（点输入框 → 点悬浮球 → 点第几条）
3. 期望：____
4. 实际：____
```

有这四行 + 一份日志，基本一次就能定位。
